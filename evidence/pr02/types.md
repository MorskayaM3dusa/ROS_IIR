# Типы сообщений — ПР02

## Основные топики

| Топик | Тип | Назначение |
|-------|-----|------------|
| `/turtle1/pose` | `turtlesim/msg/Pose` (Jazzy) | Публикуется нодой `/turtlesim`. Содержит текущее положение и ориентацию черепахи. |
| `/turtle1/cmd_vel` | `geometry_msgs/msg/Twist` | Публикуется управляющим узлом (teleop или `ros2 topic pub`). Содержит команды линейной и угловой скорости. |

## Поля сообщения `geometry_msgs/msg/Twist`

|    Поле     | Назначение |
|-------------|------------|
| `linear.x`  | Линейная скорость вдоль оси X (вперёд/назад), м/с |
| `linear.y`  | Линейная скорость вдоль оси Y, м/с |
| `linear.z`  | Линейная скорость вдоль оси Z, м/с |
| `angular.x` | Угловая скорость вокруг оси X, рад/с |
| `angular.y` | Угловая скорость вокруг оси Y, рад/с |
| `angular.z` | Угловая скорость вокруг оси Z (поворот на месте), рад/с |

В работе использовалась команда:
```bash
ros2 topic pub --once /turtle1/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 1.0}, angular: {z: 0.5}}'
```
Задаёт движение вперёд со скоростью 1.0 м/с и поворот со скоростью 0.5 рад/с.

## Поле позы

Для ROS 2 Jazzy тип позиции черепахи — `turtlesim/msg/Pose`. Поля: `x`, `y`, `theta`, `linear_velocity`, `angular_velocity`.
